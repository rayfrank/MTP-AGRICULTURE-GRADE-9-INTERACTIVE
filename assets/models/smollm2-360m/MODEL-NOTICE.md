# SmolLM2 360M Instruct

This app includes `mlc-ai/SmolLM2-360M-Instruct-q4f16_1-MLC` for optional,
on-device language generation through WebLLM.

- Upstream model: `HuggingFaceTB/SmolLM2-360M-Instruct`
- MLC distribution: `https://huggingface.co/mlc-ai/SmolLM2-360M-Instruct-q4f16_1-MLC`
- Format: MLC `q4f16_1`
- License: Apache License 2.0

The model is loaded only after the learner enables Enhanced local AI. Prompts
and generated replies remain on the device.
